# PESU-IO

Coursework, assignments, and final project completed as part of the **PESU-IO course**.

## 📂 Contents

### Assignment 1 — RAG Applications

Implemented Retrieval-Augmented Generation (RAG) systems using LlamaIndex, vector databases, embeddings, and LLMs.

- **[PDF RAG](./Assignment-1/PDF)** — RAG-based question answering over a local PDF using **LlamaIndex, Qdrant, Jina AI Embeddings, and Groq**, with LLM model comparison.
- **[Website RAG](./Assignment-1/WEBSITE)** — RAG-based question answering over website content using **LlamaIndex, Qdrant, Cohere Embeddings, and Groq**.

### Assignment 2 — Multi-Agent Research System

- **[Medical Agent](./Assignment-2/medical_agent)** — Multi-agent research workflow built with **CrewAI**, consisting of a Researcher Agent and Reporting Analyst Agent. Uses **SerperDevTool** for web research and generates a structured Markdown report.

### 🚀 Final Project — Medical Assistant Chatbot

- **[Medical Assistant Chatbot](./PROJECT)** — An **Agentic RAG-based medical chatbot** using a local medical knowledge base.

**Tech Stack:** Python · Streamlit · LlamaIndex · ReActAgent · Groq · Llama 3 70B · Jina AI Embeddings

## 🛠️ Technologies Covered

**RAG · Vector Search · LLMs · Embeddings · Qdrant · LlamaIndex · CrewAI · Agentic AI · Streamlit · Python**
